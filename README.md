# カクヨム読み上げ（非公式）

[カクヨム](https://kakuyomu.jp/) の小説を [VOICEVOX](https://voicevox.hiroshiba.jp/) で読み上げる Chrome 拡張です。話の終わりまで読むと次のエピソードへ自動で進むので、作業しながらオーディオブックのように聴き続けられます。

> このツールはカクヨム（株式会社KADOKAWA）とは関係のない非公式ツールです。

## できること

- カクヨムの話のページ右下の ▶ ボタンで読み上げを始める
- いま画面の一番上に見えている段落から読み始める
- 読んでいる段落に色を付け、画面を自動でスクロールする
- 話の最後まで読むと次のエピソードへ移動し、続けて読む
- ■ ボタンで止める。最新話まで読み終えたときも止まる
- VOICEVOX が起動していないときは、端末の日本語音声（Mac の Kyoko など）で読む

読んだ位置は拡張側では保存しません。既読の管理はカクヨム本体に任せています（実際にページを移動するので、ログインしていればカクヨムの既読も更新されます）。

## 必要なもの

- Google Chrome 116 以降（パソコン版）
- [VOICEVOX](https://voicevox.hiroshiba.jp/)（推奨。無くても端末の音声で読めます）

## 導入手順

1. [Releases](../../releases) から `kakuyomu-tts.zip` をダウンロードして展開する
2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパーモード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」を押し、展開したフォルダを選ぶ

## 使い方

1. VOICEVOX を起動しておく
2. カクヨムで読みたい話のページを開く
3. 画面右下の ▶ を押す

## 設定

ツールバーの拡張アイコンを押すと設定画面が開きます。変更は次に ▶ を押したときから反映されます。

| 項目 | 内容 |
|---|---|
| 音声エンジンの URL | 既定は `http://127.0.0.1:50021`（VOICEVOX）。AivisSpeech など VOICEVOX 互換のエンジンも、URL を変えれば使えます（`127.0.0.1` か `localhost` のみ） |
| 声（VOICEVOX） | エンジンにある声から選べます |
| VOICEVOX が使えないときの声 | 端末内の日本語音声から選べます。既定は Kyoko などの標準の声です |
| 速度 | 0.5〜2.0 倍 |
| 段落の間 | 段落と段落の間に空ける無音の長さ。0〜2.0 秒（既定 0.7 秒） |

## よくある質問

**「VOICEVOX（音声エンジン）に接続できません」と出る**
VOICEVOX が起動しているか確認してください。ポートを変えている場合は、設定画面の URL を合わせてください。

**漢字の読み間違いを直したい**
VOICEVOX の「読み方＆アクセント辞書」に単語を登録すると、この拡張での読み上げにも反映されます。

**再生中にページを移動したら止まった**
仕様です。拡張が自動で次の話へ進むとき以外にページを移動・再読み込みすると、読み上げを止めます。

## プライバシー

本文のテキストは、設定した手元の音声エンジン（`127.0.0.1` / `localhost`）か、端末内の音声にだけ渡します。Chrome の「Google 日本語」のように外部サーバーで音声を作る声は使いません。外部サーバーへの送信や利用状況の収集は一切行いません。

## 音声のクレジットについて

この拡張は音声を保存・配布しません。読み上げた音声を録音して公開する場合などは、[VOICEVOX の利用規約](https://voicevox.hiroshiba.jp/term/)と、各キャラクターの利用規約に従ってください。

## 開発

```sh
npm install
npm test             # 自動テスト
npm run package      # dist/kakuyomu-tts.zip を作る
```

カクヨムのページ構造に依存する部分は `src/episode.js` 冒頭の `SELECTORS` にまとめています。カクヨム側の変更で動かなくなったら、まずここを確認してください。リリース前の確認項目は [docs/e2e-checklist.md](docs/e2e-checklist.md) にあります。
