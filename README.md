# カクヨム読み上げ（非公式）

[カクヨム](https://kakuyomu.jp/)の小説を[VOICEVOX](https://voicevox.hiroshiba.jp/)で読み上げるChrome拡張です。話の最後まで読むと次のエピソードへ自動で移るので、作業をしながらオーディオブックのように聴き続けられます。

> このツールは、カクヨムを運営する株式会社KADOKAWAとは関係のない非公式ツールです。

## できること

カクヨムの話のページを開くと、右下に▶ボタンが表示されます。読み上げの開始位置は、▶を押した時点で画面の一番上に見えている段落です。読んでいる段落には色が付き、画面も読み上げに合わせてスクロールします。

話の最後まで読むと、拡張が次のエピソードへ移動して冒頭から読み続けます。読み上げが止まるのは、■ボタンを押したときと、最新話を読み終えたときです。VOICEVOXが起動していないときは、MacのKyokoなど端末に入っている日本語音声で読み上げます。

拡張は読んだ位置を保存しません。既読の管理はカクヨム本体に任せています。拡張は実際にページを移動するので、カクヨムにログインしていれば既読も更新されます。

## 必要なもの

パソコン版のGoogle Chrome 116以降が必要です。音声エンジンには[VOICEVOX](https://voicevox.hiroshiba.jp/)をおすすめします。VOICEVOXが無くても、端末の日本語音声で読み上げられます。

## 導入手順

1. [Releases](../../releases)から`kakuyomu-tts.zip`をダウンロードし、展開してください。
2. Chromeで`chrome://extensions`を開いてください。
3. 右上の「デベロッパーモード」をオンにしてください。
4. 「パッケージ化されていない拡張機能を読み込む」を押し、展開したフォルダを選んでください。

## 使い方

VOICEVOXを起動してから、カクヨムで読みたい話のページを開き、画面右下の▶を押してください。

## 設定

▶の左上にある歯車ボタンを押すと、設定画面が開きます。ツールバーの拡張アイコンからも開けます。

読み上げ中に変えた設定がすぐ反映されるのは、声、速度、段落の間の3つです。いずれも次の文から切り替わります。音声エンジンのURLだけは、次に▶を押したときから反映されます。

| 項目 | 内容 |
|---|---|
| 音声エンジンのURL | 既定は`http://127.0.0.1:50021`（VOICEVOX）です。AivisSpeechなどVOICEVOX互換のエンジンも、URLを変えれば使えます。指定できるホストは`127.0.0.1`と`localhost`だけです |
| 声（VOICEVOX） | 音声エンジンにある声から選べます |
| VOICEVOXが使えないときの声 | 端末内の日本語音声から選べます。既定ではKyokoなどの標準的な声を使います |
| 速度 | 0.5〜2.0倍の範囲で変えられます |
| 段落の間 | 段落と段落の間に空ける無音の長さです。0〜2.0秒の範囲で変えられ、既定は1.0秒です |

## よくある質問

### 「VOICEVOX（音声エンジン）に接続できません」と表示される

VOICEVOXが起動しているか確認してください。VOICEVOXのポート番号を変えている場合は、設定画面の音声エンジンのURLを同じ番号に合わせてください。

### 漢字の読み間違いを直したい

VOICEVOXの「読み方＆アクセント辞書」に単語を登録してください。登録した読みは、この拡張の読み上げにも反映されます。

### 読み上げ中にページを移動したら止まった

拡張は、自分で次の話へ移動するとき以外のページ移動や再読み込みを検知すると、読み上げを止めます。続きを聴くときは、移動先のページで▶を押してください。

## プライバシー

拡張は、本文のテキストを設定した手元の音声エンジン（`127.0.0.1`または`localhost`）か、端末内の音声にだけ渡します。Chromeの「Google 日本語」のように外部のサーバーで音声を作る声は使いません。外部サーバーへの送信や利用状況の収集もしません。

## 音声のクレジット

この拡張は音声を保存も配布もしません。読み上げた音声を録音して公開する場合は、[VOICEVOXの利用規約](https://voicevox.hiroshiba.jp/term/)と各キャラクターの利用規約に従ってください。

## 開発

```sh
npm install
npm test             # 自動テスト
npm run package      # dist/kakuyomu-tts.zip を作る
```

カクヨムのページ構造に依存するセレクタは、`src/episode.js`冒頭の`SELECTORS`にまとめています。カクヨム側の変更で拡張が動かなくなったときは、まずこの定数を確認してください。リリース前の確認項目は[docs/e2e-checklist.md](docs/e2e-checklist.md)にあります。
